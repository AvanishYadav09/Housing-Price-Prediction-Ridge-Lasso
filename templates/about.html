Project Mission & Purpose
Production ML Architecture

HomeValue was engineered to bridge the gap between academic Machine Learning exploration in Jupyter Notebooks and production-grade full-stack web platforms. The platform operationalizes a comparative econometric study of Linear Regression (OLS), Ridge Regression (L2), and Lasso Regression (L1) under conditions of acute structural multicollinearity.

Rather than merely outputting a single prediction, HomeValue serves as an educational and analytical tool, demonstrating in real-time how L1 penalty performs sparse feature selection while L2 penalty stabilizes variance across collinear features.

Dataset Disclosure & Controlled Generation
Synthetic Benchmark
Important Notice on Dataset Origin: The dataset used by HomeValue is a carefully crafted synthetic dataset (N = 2,000 properties, seed = 42) developed specifically to benchmark multicollinearity and regularization. Valuations provided by this system are econometric model demonstrations and must not be used as official commercial real-estate appraisals.

Mathematical Generation Formula

As codified in the project notebook, the ground-truth target is defined by:

sale_price = 50,000 + 150 × living_area_sqft + 10 × lot_size_sqft + 15,000 × garage_capacity + 8,000 × room_count + ε(0, 25,000)

Two deliberate collinear features were injected:

  • total_interior_sqft = living_area_sqft + Normal(0, 100)
  • footprint_sqft = living_area_sqft × 0.75 + Normal(0, 80)

Limitations & Future Scope
Technical Constraints
  • Linear Function Assumption: All models assume linear relationships between continuous square footage and sale price. Non-linear price accelerations or threshold boundaries are not modeled.
  • Absence of Geographic Coordinates: The model evaluates architectural dimensions only; real-world property prices are heavily influenced by micro-location, school districts, and transit access.
  • Fixed Regularization Hyperparameters: Current deployment fixes α = 10 for Ridge and α = 1,000 for Lasso based on the notebook's cross-validated optima. Dynamic hyperparameter grid-search via interactive slider can be added in future iterations.
